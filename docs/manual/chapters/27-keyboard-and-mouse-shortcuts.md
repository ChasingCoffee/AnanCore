## Keyboard and mouse shortcuts

Press **?** anywhere in ANAN Core to show this list on screen. Keys are ignored while you are typing in a text field.

### Tuning and display

- **← / →** — tune down / up by the current step.
- **↑ / ↓** — zoom the panadapter in / out.
- **Alt + ↑ / ↓** — zoom the world-map background.
- **← / → with the filter ribbon open** — move the filter edge instead of tuning.

### Transmit

- **Space (hold)** — push-to-talk. Transmits while the key is held and releases when you let go.

### Workspaces

- **/** — jump to the logbook callsign box.
- **Alt + 8** — toggle the FT8 workspace.
- **Esc** — close Settings, popovers and floating windows.
- **?** — show or hide the shortcut list.
- **Ctrl + Shift + R** — hard-reload the interface after an update.

### Mouse and touch

- **Scroll on the VFO digits** — step that digit; **click the digits** — type a frequency in kHz.
- **Scroll on the panadapter** — tune by the current step; **drag** — slide the view; **pinch** — zoom (touch).
- Slider fine-trim and panel-specific keys are listed in each panel's tooltip.
